# 🥕 당근톤

평범한 판매글을 당근 중고거래 말투로 바꾸고, 상품 사진을 가정집 배경으로 합성하는 **프롬프트 런처**입니다.

`index.html` 파일 하나가 전부입니다. 빌드 없음, 서버 없음, 의존성 없음.

---

## 어떻게 동작하나

AI API를 직접 호출하지 않습니다. **프롬프트를 만들어 사용자를 ChatGPT로 보내주는 방식**입니다.

| 기능 | 동작 |
|---|---|
| 글 바꾸기 | 프롬프트를 만들어 `https://chatgpt.com/?q=...` 로 새 창 → **자동 전송됨** |
| 사진 바꾸기 | 프롬프트를 `?q=` 로 **먼저 자동 전송**하고, 사진은 클립보드에 넣어둠 → 사용자는 `Ctrl+V` + `Enter` |

### 사진 기능이 순서를 뒤집는 이유

이미지 파일은 URL 로 보낼 수 없다. 그렇다고 `?q=` 를 쓰면 사진을 붙이기도 전에
프롬프트가 전송돼 버린다. 그래서 **일부러 먼저 보낸다.**

1. "다음 메시지에 사진을 붙여넣을 테니 받으면 이 작업을 해줘" + 편집 지시를 자동 전송
2. 프롬프트 끝에 `지금은 "사진 올려주세요" 한 줄만 답하고 기다려` 를 붙여 첫 턴을 짧게 끊는다
3. ChatGPT 가 대기 상태가 되면 사용자는 `Ctrl+V` → `Enter`

사이트에 올린 사진은 버튼을 누르는 순간 PNG 로 변환돼 클립보드에 들어가므로,
사용자가 파일을 다시 찾아 끌어다 놓을 필요가 없다.

### 이 구조를 택한 이유

- **운영 비용 $0** — API 호출이 없어서 사용자가 몇 명이든 호스팅비만 나감
- **API 키 발급 불필요** — 사용자는 ChatGPT 계정만 있으면 됨
- **개인정보 저장 안 함** — 서버가 없음. 글과 사진은 브라우저 메모리에만 있다가 탭 닫으면 사라짐

### 왜 ChatGPT 하나로 좁혔나

프리필이 되는 곳이 ChatGPT 뿐이다. Gemini 는 `?prompt=`, `?q=` 둘 다 입력창이
비어 있고(검색하면 "된다"는 글이 나오지만 전부 크롬 확장 프로그램이 필요한 방법이다),
ChatGPT 도 `?prompt=` 는 동작하지 않는다. 동작이 다른 버튼을 나란히 두면
사용자가 어느 쪽이 자동인지 알 수 없어 오히려 혼란스러웠다.

## 배포

정적 파일 하나라 어디에 올려도 됩니다.

### Cloudflare Pages (추천 · 무료)

```bash
npm i -g wrangler
wrangler pages deploy . --project-name=danggeun-tone
```

→ `https://danggeun-tone.pages.dev` 발급. 커스텀 도메인 연결도 무료입니다.

### GitHub Pages

리포지토리에 `index.html` 를 올리고 Settings → Pages → Branch `main` / 폴더 `/` 선택.

### Vercel

```bash
npx vercel --prod
```

### 로컬에서 확인만

`index.html` 을 브라우저로 그냥 열어도 동작합니다.
단, `file://` 은 보안 컨텍스트가 아니라 클립보드 API가 막힐 수 있습니다 (구형 `execCommand` 로 자동 폴백되긴 합니다). 정확히 보려면 로컬 서버를 쓰세요:

```bash
npx serve .
```

## 검증한 것

실제 브라우저로 끝까지 테스트했습니다.

- ChatGPT `?q=` 자동 전송 — **동작함**, 로그인 없이도 됨
- ChatGPT `?prompt=` — **동작 안 함** (입력창 비어 있음). 전송 없이 채우는 방법은 없다
- Gemini `?prompt=` / `?q=` 프리필 — **동작 안 함** (그래서 ChatGPT 로 좁힘)
- 순서 뒤집기 — ChatGPT 가 `사진 올려주세요` 한 줄만 답하고 대기하는 것까지 확인
- 사진 클립보드 복사 — 3000×2000 → 1536×1024 축소 후 PNG 변환.
  `clipboard.write()` 가 `window.open()` 보다 먼저 호출돼 제스처가 유지되는 것 확인.
  `toBlob` 은 비동기라 await 하면 Safari 가 거부하므로 `Promise<Blob>` 을 `ClipboardItem` 에 그대로 넘긴다
- chatgpt.com URL 길이 한계 — 32,000자까지 HTTP 200. 안전하게 16,000자로 제한, 초과 시 클립보드 폴백
  - 한글은 인코딩 시 글자당 9바이트라, 판매글 **약 1,200자까지 자동 전송**됨
- 한국어 조사 — 받침 판별해서 `을/를`, `이/가` 자동 선택 (가방→을, 믹서기→를)
- 팝업 차단 — `copy()` 와 `window.open()` 을 모두 클릭 핸들러 안에서 동기 호출해 회피

## 커스터마이징

`index.html` 안의 두 함수만 고치면 됩니다.

| 함수 | 하는 일 |
|---|---|
| `buildTextPrompt()` | 당근 말투 변환 프롬프트 |
| `buildImagePrompt()` | 배경 합성 프롬프트 |

프롬프트에 넣어둔 안전장치:

- 원본에 없는 **가격·구매시기·보증기간·하자유무**는 지어내지 말 것 → `○○` 로 비워둠
- 판매 사유가 **제품 상태와 모순되지 않게** (미개봉인데 "몇 번 써봤는데" 금지)
- 이미지는 **물건의 모양·색상·로고·흠집을 원본 그대로 유지**, 미화 금지

## 주의

- 판매 사유는 AI가 지어내므로 **실제와 다르면 반드시 고쳐서** 올려야 합니다.
- 배경 합성 사진만 올리면 흠집·사용감이 가려질 수 있습니다. **실제 상태 사진도 함께** 올리지 않으면 허위매물이 됩니다.
- 당근톤은 **당근마켓과 무관한 비공식 도구**입니다.
